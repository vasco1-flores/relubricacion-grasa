# Inicio Lubricación MAPA

Dashboard de lubricación de Planta MAPA: consulta de TAG, análisis de rutas, MAF, base de datos de lubricantes (con hojas de datos de seguridad y compatibilidad), calculadora, muestras de aceite y mapa de maderas.

El contenido está cifrado (AES-256-GCM, clave derivada con PBKDF2-SHA256 de 600.000 iteraciones). Sin la clave, la página solo muestra la pantalla de ingreso. La clave no se guarda en este repositorio.

Sitio: https://vasco1-flores.github.io/relubricacion-grasa/

Para actualizar, reemplace `index.html` por la versión nueva generada desde la base de datos.
